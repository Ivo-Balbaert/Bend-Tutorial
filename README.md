This is a hands-on beginners tutorial for Bend.
The primary reason for this tutorial is that the official GitHub repo https://github.com/bendlang/bend
or Bend website (https://bend-lang.com/) don't have any such start-up tutorial. 

The tutorial (in `Bend_Tutorial.md`) uses a hands-on style, with code examples in subfolder `code`, try out suggestions and exercises in the subfolder with that name.

The main target are Python developers, or other developers with a general programming experience.  

It is carefully revised and tested for Bend v 2.0.37.
It will be kept up-to-date with Bend's changes. Comments and corrections welcome!
